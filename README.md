# PokeApi Project

This is a simple Python project that fetches and displays data from the [PokeAPI](https://pokeapi.co/). It allows users to enter the name of a Pokémon and get information such as its type, weight, height, and abilities.

---

## Features

- Fetch Pokémon data using PokeAPI.
- Display name, types, weight, height, and abilities.
- Handles user input and invalid names with basic error messages.

---

## Technologies Used

- Python 3
- `requests` library

---

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Selinoztrk/PokeApi.git
   cd PokeApi
   ```
2. Install required library:
   ```bash
   pip install requests
   ```
3. Run the script:
   ```bash
   python main.py
   ```
4. Enter a Pokémon name when prompted to see its details.
